title: Sync across devices
---

- **Sync devices** keeps this graph on your other phones and computers with a secret code
- The same dialog can copy a read-only link if you only want to show someone the graph
- Anyone with the code can read and overwrite the graph
- If two devices edit at once, you choose which copy to keep
- Toolbar is **Add goal**, **Link player**, and **Sync devices**; extra actions live under ⋯
- Hide completed is a control on the canvas, next to zoom
